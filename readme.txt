Packages required:
    - pandas
    - numpy
    - matplotlib
    - seaborn

401k Dataset:
    Run 401k_model.ipynb to create the synthetic SCM, generate data and store the ground truth in 401k_effect.pkl.
    Then, run 40k_sampled.ipynb to generate the plots.

Synthetic Data:
    Run sim_post-treatment.ipynb to generate the plots.
